# 🏫 MMVSmart - Makudmuang Smart Class System
ระบบบันทึกและสรุปผลเวลาเรียน & ระบบเลือกกิจกรรมชุมนุมออนไลน์
โรงเรียนมกุฎเมืองราชวิทยาลัย (สำนักงานเขตพื้นที่การศึกษามัธยมศึกษาชลบุรี ระยอง)

---

## 🌟 ฟีเจอร์หลัก (Key Features)

### 👨‍🏫 1. ระบบครูและบุคลากร (Teacher Portal - `teacher.html`)
* **🏠 แดชบอร์ดสรุปภาพรวม:** ข้อมูลนักเรียนในห้องที่ปรึกษา, คะแนนความประพฤติ, คะแนนความดี, จิตอาสา
* **📅 ระบบเช็คชื่อเข้าเรียนประจำวัน:**
  * เชื่อมโยงข้อมูล Face Arrival (สแกนใบหน้าเข้าประตูโรงเรียน)
  * ปุ่มสถานะ 5 รูปแบบ: มาเรียน, ลากิจ, ลาป่วย, มาสาย, ขาดเรียน
  * รองรับ Responsive เต็มรูปแบบบนมือถือ (Mobile Friendly)
  * แจ้งเตือนเลขที่ที่ยังไม่ได้เช็คชื่อด้วยรูปแบบ Badge Pills ป้องกันความผิดพลาด
* **📊 รายงานและสถิติภาพรวม:**
  * สรุปเปอร์เซ็นต์การเข้าเรียนแยกตามระดับชั้นและห้องเรียน
  * ส่งออกรายงานในรูปแบบ PDF และ Excel ได้ทันที
* **🧑‍🎓 สรุปเวลาเรียนรายบุคคล:**
  * เลือกระบุช่วงวันที่เริ่มต้น - สิ้นสุดเพื่อคำนวณสถิติ
  * ส่งออกรายงาน PDF / Excel
* **⚠️ ระบบตัดคะแนนความประพฤติ:**
  * ค้นหานักเรียนด้วยรหัสประจำตัว หรือ พิมพ์ชื่อ-สกุล (Instant Match)
  * ตะกร้าตัดคะแนนแบบรายกลุ่ม (Batch Deductions)
* **🌟 ระบบบวกคะแนนความดี:**
  * จัดอันดับ Top Rewards คะแนนความดีสะสมทั้งโรงเรียน
* **🤝 ระบบบันทึกนักเรียนจิตอาสา:**
  * บันทึกรูปภาพกิจกรรมกลุ่มพร้อมระบุจำนวนชั่วโมงจิตอาสา
* **🎪 ระบบจัดการชุมนุม (Club Management):**
  * สร้างชุมนุม, จัดการสมาชิกในชุมนุม (เพิ่ม/ลบ)
  * เช็คชื่อการเข้าเรียนชุมนุมรายสัปดาห์
  * ผู้ดูแลระบบชุมนุม (Club Admin) สามารถเปิด-ปิดระบบรับสมัครและพิมพ์รายงาน

---

### 🧑‍🎓 2. ระบบนักเรียน (Student Portal - `student.html`)
* **เข้าสู่ระบบด้วยรหัสนักเรียน**
* **ตรวจสอบและลงทะเบียนเลือกชุมนุมออนไลน์:**
  * แสดงจำนวนที่นั่งคงเหลือแบบ Real-time
  * ป้องกันการเลือกซ้ำซ้อนหรือเลือกชุมนุมที่เต็มแล้ว
  * พิมพ์ใบสมัครชุมนุม (PDF)

---

## 🛠️ โครงสร้างระบบ (Tech Stack & Architecture)
* **Frontend:** HTML5, CSS3 (Bootstrap 5.3 + FontAwesome 6 + Prompt Font), JavaScript (ES6+), SweetAlert2, HTML2PDF.js
* **Backend:** PHP 8.x (REST API / Action-based Router via `api.php`)
* **Database:** MySQL / MariaDB (PDO with Prepared Statements)
* **Hosting / Web Server:** Nginx + PHP-FPM

---

## 📂 โครงสร้างไฟล์ (File Structure)
* `index.php` : หน้า Routing หลักของระบบ
* `config.php` : การเชื่อมต่อฐานข้อมูล MySQL และการตั้งค่าพื้นฐาน
* `api.php` : API Endpoint จัดการฟังก์ชันทั้งหมดของระบบ
* `teacher.html` : หน้าต่างการทำงานหลักของครูและผู้ดูแลระบบ
* `student.html` : หน้าต่างการลงทะเบียนเลือกชุมนุมของนักเรียน
* `google-mock.js` : ตัวแปลงคำสั่ง `google.script.run` ให้สื่อสารกับ PHP API
* `logo.png` : ตราสัญลักษณ์โรงเรียนมกุฎเมืองราชวิทยาลัย
* `.htaccess` : การตั้งค่า DirectoryIndex และความปลอดภัยสำหรับ Apache/Nginx
